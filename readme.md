# TradingView Watchlist API Manipulation

Custom Jupyter notebooks for interacting with the TradingView internal API to automate watchlist management.

## Features
- **API Interaction**: Scripts to programmatically add, remove, or modify watchlist symbols.
- **Financial Automation**: Eliminates manual updates for large symbol sets.
- **Jupyter Native**: Easy-to-run notebooks with step-by-step guidance.
